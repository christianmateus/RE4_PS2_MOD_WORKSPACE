Due to countless pms by tyrant, I've decided to make this tutorial to explain how to modify animations (about time SOMEBODY did ).

The tools you'll need are GCA Extractor, DatExtract, DatRepack or DatInjector (I advise getting used to the injector, as it's much easier).

Extract the files from em.dat using the GCA Extractor. This should create a new folder called em in your root RE4 folder. Inside this flder are dat files which contain the model movement data (BIN), specific effects (EFF), animation sequences (SEQ) and animations themselves (FCV).

Use the animation directory thread in this section to identify the number of the file you want. For example: If you want to make Leon perform a drop kick in replace of his knee shot kick, you have to do the following. In em39.dat (enemy Krauser) there's a file called 277_em39.fcv this file is the drop kick Leon pulls off. Use the DatExtract to get to this file, then use the following command line with the DatInjector to replace Leon's knee kick.

datinject.exe pl00.dat 277_em39.FCV 33
datinject.exe pl08.dat 277_em39.FCV 33
datinject.exe pl09.dat 277_em39.FCV 33
datinject.exe pl10.dat 277_em39.FCV 33
datinject.exe pl19.dat 277_em39.FCV 33

Then you're done. Be careful what animation you switch because some are vital to the game and may cause the game to crash. Making Leon run differently when he's injured will do this.
