## Português

A versão **v0.2.2** ainda está em desenvolvimento. Atualmente, a ferramenta suporta **apenas edição de texturas de cenários (SMD)**.

### Funcionalidades
- Visualização e substituição de texturas
- Importação/exportação de PNG
- Edição de mipmaps
- Resize, Rotate e Flip
- Conversão entre 4-bit e 8-bit

### Dependências

Atualmente, algumas funcionalidades dependem das seguintes ferramentas externas:

- **DAT Tool** (dentro do toolset) — [https://residentevilmodding.boards.net/thread/9780/2018-re4uhd-toolset-persia-updated]()
- **ISOAFS v1.3.3** — [https://github.com/christianmateus/RE4_PS2_ISOAFS_MANAGER]()
- **TPL Manager v1.3.2** — [https://github.com/christianmateus/RE4_PS2_TPL_Manager]()
- **PCSX2 2.7+** — [https://pcsx2.net/downloads/]()

Mais funcionalidades serão adicionadas futuramente.

## English

Version **v0.2.2** is still a **Work in Progress**. Currently, the tool supports **scenario (SMD) texture editing only**.

### Features
- Texture preview and replacement
- PNG import/export
- Mipmap editing
- Resize, Rotate and Flip
- 4-bit / 8-bit conversion

Some features currently depend on the following external tools:
